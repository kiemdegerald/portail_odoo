Gestion Recrutement

Site web ↔ Pipeline de recrutement Odoo

Passerelles sécurisées entre Odoo et le site web externe :

  • Diffusion des offres (hr.job) publiées, avec leurs questions de filtre paramétrables.
  • Réception des candidatures (hr.applicant) avec CV et lettre de motivation, rattachées à la bonne offre.
  • Questions de filtre configurables depuis l'interface (Oui/Non, choix multiple, texte), avec règle automatique : bloquer, archiver ou changer d'étape selon la réponse.
  • Synchronisation « push » vers le site (bouton ou automatique).

Le suivi du recrutement reste géré par le module Recrutement standard.
